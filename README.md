# Vulhub‑Lab
🔐 Web安全漏洞复现练习仓库

> 声明：所有实验均在本地Docker靶场完成，仅用于安全技术学习，禁止对未授权资产进行渗透测试。

## 项目介绍
本仓库为个人网络安全学习笔记，基于Vulhub靶场复现常见Web漏洞。
每一个独立文件夹对应一次完整的漏洞实验，文件夹内README.md包含：漏洞原理、环境搭建命令、漏洞利用过程、漏洞修复建议。
